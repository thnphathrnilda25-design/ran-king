# Tee Best Ran-King
Ranking video maker. Runs fully in the browser: upload clips, rank them, style the title, export a vertical video.

## Link import (local only)
Paste TikTok / Instagram / YT Shorts links by running `node server.mjs` with yt-dlp installed, then open http://localhost:3000. Not available on the hosted page. Use only content you have rights to.
